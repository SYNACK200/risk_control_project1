# 模板管理增强方案

> 一句话：模板从「只能启用」变成**可编辑（出新生效版本）、可试跑验证、可看使用效果、可导入导出**的完整生命周期。

## 1. 新增能力

| 能力 | 接口 | 说明 |
| --- | --- | --- |
| 编辑映射 | `PUT /templates/{id}` | 保存生成**新版本草稿**（旧版本保留为 disabled） |
| 复制 | `POST /templates/{id}/duplicate` | 复制为新草稿，版本号 +1 |
| 停用 | `POST /templates/{id}/disable` | 不停用则同银行只能一个启用版本 |
| 删除 | `DELETE /templates/{id}` | 被流水用过则 409，要求先停用 |
| 使用统计 | `GET /templates/{id}/stats` | 用了几条、成功/失败、成功率、平均笔数、零笔任务数 |
| 试跑 | `POST /templates/{id}/preview` | 上传样例 PDF，按该模板解析，**不落库**，返回笔数/前 10 行/warnings |
| 导出 | `GET /templates/{id}/export` | 模板 JSON 下载 |
| 导入 | `POST /templates/import` | 从 JSON 建草稿（版本号自动递增） |

原有「标记外推」保留，收进折叠面板。

## 2. 版本规则

1. 同一银行可有多个版本；**只有一个是 enabled**。
2. 编辑保存 → 新版本 `latest+1`、状态 draft，旧版本 disabled。
3. 复制 → 同样新建版本，内容同源。
4. 启用（publish）→ 同银行其它版本自动 disabled。
5. 删除只允许「没被任何流水用过」的版本。

## 3. 页面结构

1. 表格：ID / 银行 / 版本 / 状态 / 使用（点「查看」出统计）/ 成功率 / 字段数 / 操作。
2. 操作：启用、停用、编辑、复制、试跑、导出、删除。
3. 编辑面板：银行代码 + 字段映射 JSON（提示可用字段名）。
4. 试跑面板：选样例文件 + 口令 → 结果（笔数、前 10 行、warnings）。
5. 新建/导入面板：新建草稿、粘贴 JSON 导入。
6. 折叠：标记外推（原能力）。

## 4. 实测

| 操作 | 结果 |
| --- | --- |
| 统计 #1 | tasks_total 1 / done 1 / failed 0 / 成功率 100% / 平均 191 笔 / 零笔 0 |
| 复制 #1 | 得到 #2 v2 草稿 |
| 试跑 #1（建行 30 页样例） | 走模板未命中 → 回退通用解析，570 笔，warnings 明确 |
| 导出 #1 | 200，`template-ICBC-v1.json` |
| 页面复制 | 提示「已复制为新草稿」，表格 2→3 行 |
| 页面编辑 | 打开面板「编辑模板 #2（保存生成 v3 草稿）」 |

## 5. 边界

| # | 边界 | 说明 |
| --- | --- | --- |
| 1 | 试跑只返回前 10 行 | 完整核对要下载 CSV |
| 2 | 编辑用 JSON 输入 | 没用可视化列选择器；外推面板可辅助 |
| 3 | 删除不级联历史 | 被用过就不能删，避免报告无法追溯 |
| 4 | 没有审批流 | 编辑即出草稿，启用即时生效 |
