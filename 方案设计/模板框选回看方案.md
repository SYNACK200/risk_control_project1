# 模板框选回看方案

> 工作人员不用看坐标/列序号：打开模板就能看到「当时选的是哪一块」，以图片形式呈现。

## 1. 之前为什么看不到

| 项 | 之前 |
| --- | --- |
| 存储 | 只存 `field_map`（字段→列序号）与 `header_columns`（表头文字） |
| 缺什么 | 没存建模板用的样本文件，也没存标注点的坐标 |
| 结果 | 页面上只能看到 `amount: 8` 这种抽象映射 |

## 2. 现在的做法

| 环节 | 做法 |
| --- | --- |
| 建模板 | `/templates/infer` 保存草稿时，把样本 PDF 存进 `file_obj` + 磁盘，并把标注点换算成方框存进 `template.layout` |
| 方框来源 | x 取推断出的列范围（x0~x1），y 取表头文字位置；找不到表头就用标注点 ±12pt |
| 回看接口 | `GET /templates/{id}/layout` 返回页面尺寸与全部方框；`GET /templates/{id}/layout.png` 直接返回画好框的页面图 |
| 页面 | 模板管理每行「回看框选」→ 展开图片 + 图例（字段中文名 · 对应列名 · 颜色） |

## 3. 实测

| 项 | 结果 |
| --- | --- |
| 新建模板（CMB，3 个标注点） | `template_id=4`，`layout.boxes=3`，页面 595×842 |
| layout.png | **200 image/png，62,740 字节**，1157×1638 像素 |
| 图中颜色 | 检测到红/蓝/绿三色像素（310/301/240 采样点）→ 三个框都画上了 |
| 页面 | 图片 830×1175 渲染，图例「交易日期 / 金额 / 余额」 |
| 旧模板（1–3，无样本） | 提示「该模板建于保存样本功能之前，只记录了列序号，无法回看当时的框选」 |

## 4. 边界

| # | 边界 |
| --- | --- |
| 1 | 只对**新建**（或重新标注保存）的模板可回看；历史模板需重新标注一次 |
| 2 | 方框是「列范围 + 表头高度」的近似，不是逐像素精确框；用途是让人看懂选的是哪列 |
| 3 | 样本文件存本地 `backend/storage/uploads/`，按 sha256 去重；删样本会影响回看 |
| 4 | 目前只渲染标注点所在页；跨页模板需逐页切换（已预留 page 参数与分页按钮） |
