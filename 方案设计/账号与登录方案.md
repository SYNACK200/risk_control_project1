# 账号与登录方案

> 一句话：**借款侧自助注册登录、银行侧账号登录；令牌区分身份，数据按归属隔离。**

## 1. 角色

| 角色 | 入口 | 能做什么 |
| --- | --- | --- |
| borrower（借款侧） | 5173 | 注册、登录、上传自己的流水、看自己的任务与报告 |
| banker（银行侧） | 5174 | 看全部流水、报告、回收站、模板、风控参数、客户与账户、审计 |

## 2. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/auth/register` | 自助注册（固定为 borrower），返回令牌 |
| POST | `/auth/login` | 用户名 + 密码 → 令牌（12 小时） |
| GET | `/auth/me` | 当前账号信息 |
| POST | `/auth/change-password` | 旧密码换新密码 |
| GET | `/auth/users` | 账号列表（仅银行侧） |
| POST | `/auth/users` | 创建账号（仅银行侧，可建 banker/borrower） |

## 3. 令牌与存储

| 项 | 做法 |
| --- | --- |
| 令牌格式 | `base64(payload).base64(HMAC-SHA256(payload))` |
| payload | `{uid, role, exp}`，有效期 12 小时 |
| 密钥 | 环境变量 `AUTH_SECRET`，缺省 `dev-secret-change-me`（**生产必须改**） |
| 前端存储 | localStorage `bs_token`（令牌）+ `bs_user`（展示用） |
| 失效处理 | 任何接口 401 → 清令牌并回到登录页 |

## 4. 密码

- 哈希：PBKDF2-HMAC-SHA256，120,000 次，随机 16 字节盐；
- 存储格式：`pbkdf2$sha256$120000$salt$hash`；
- 明文不落库、不写日志、不进审计；
- 初始管理员：首次启动若无银行侧账号，创建 `admin`，密码取 `ADMIN_PASSWORD`，默认 `admin123`，启动日志提示尽快修改。

## 5. 数据隔离

| 数据 | 规则 |
| --- | --- |
| 任务列表 | 银行侧看全部；借款侧只见 `task.user_id = 自己` |
| 任务详情 / 报告 / 明细 / 导出 | 同上，越权返回 404（不暴露存在性） |
| 回收站、重解析、模板、阈值、实体、审计 | 仅银行侧（403） |
| 上传 | 自动写 `task.user_id = 当前账号` |

## 6. 部署要点

1. `AUTH_SECRET` 设成随机长串；换密钥会让所有已发令牌失效。
2. 生产必须 HTTPS；令牌是 Bearer，明文传输等于泄露。
3. `LOCAL_ACCESS_PASSWORD` 现在只是可选总开关；配了就要求所有请求都带这个口令，通常**不要**和账号体系同时开，避免双重 Bearer 冲突（当前实现里账号令牌与总开关共用同一个 Authorization 头，二选一）。
4. 默认 admin 密码必须改：登录后调 `/auth/change-password`。

## 7. 实测

| 场景 | 结果 |
| --- | --- |
| 首次启动 | 自动创建 admin，登录返回 banker |
| 注册 zhang3 | 成功，role=borrower |
| 借款侧 /tasks | 3 条（自己的） |
| 银行侧 /tasks | 15 条（全部） |
| 借款侧访问 /entities | 403 |
| 错令牌 | 401 |
| 银行端页面 | 登录 admin/admin123 → 列表 16 行、右上「银行侧 · 系统管理员」 |
| 借款端页面 | 登录 zhang3 → 上传页、右上「借款侧 · 张三」 |

## 8. 边界

| # | 边界 | 说明 |
| --- | --- | --- |
| 1 | 没有找回密码 | 只能由银行侧管理员重置（可后续加 `/auth/users/{id}/reset-password`） |
| 2 | 没有登录失败次数限制 | 建议加（BE-20a 有口令尝试审计可复用） |
| 3 | 没有刷新令牌 | 12 小时到期需重新登录 |
| 4 | 借款侧注册无手机/邮箱验证 | 生产需要实名或验证码 |
| 5 | 旧任务 `user_id` 为空 | 只有银行侧能看到；归属历史数据需回填 |
