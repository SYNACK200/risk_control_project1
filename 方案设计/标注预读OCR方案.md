# 标注前 OCR 预读（v0.7.1）

> 标注页载入文件后，先识别银行与表头，给出建议标注，用户点一下即可采用。

## 1. 接口 `POST /templates/probe`

| 输入 | 输出 |
| --- | --- |
| 文件（PDF，可带口令）、password | `bank_name/bank_code`、`rotation`、`page_size`、`headers[]`（表头词 + 坐标）、`suggestions[]`（字段 + 列名 + 坐标） |

实现：只读第 1 页；词坐标乘 `rotation_matrix` 归一化（旋转件也能识别）；银行名用 `BANK_ALIASES` 匹配；表头行用 `detect_header_row`（词数最多 + 短中文占比高）；字段用 `FIELD_BY_HEADER` 表头映射。**不落库、不建模板**。

## 2. 前端行为

| 时机 | 行为 |
| --- | --- |
| 载入 PDF | 自动调 probe，显示「银行：中国工商银行（ICBC）· 旋转 90° · 表头 11 列」+ 表头词预览 |
| 点「采用建议标注」 | 把建议列写入第一张表的 `columns`（没有表就先建一张覆盖整页的表），并把 `bank_code` 填好 |
| 图片件 | 不做预读（PDF 之外没有文字层），仍手动框选 |

## 3. 实测（真实工行件，8 页旋转 90°，口令 719028）

| 输出 | 值 |
| --- | --- |
| 银行 | **中国工商银行 / ICBC** |
| 旋转 | 90° |
| 表头 | **11 列**：交易日期 / 账号 / 储种 / 序号 / 币种 / 钞汇 / 摘要 / 地区 / 收入支出金额 / 余额 / 渠道 |
| 建议标注 | **7 个字段**：txn_date、account_no、currency、summary、amount、balance、channel |

## 4. 边界

| # | 边界 |
| --- | --- |
| 1 | 只读第 1 页；表头在后页的版式识别不到 |
| 2 | 表头行判定依赖「短中文词多」；全英文/无表头版式会退回手动 |
| 3 | 建议列宽固定 0.07（页面比例），需要在画布上微调 |
| 4 | 图片件不做预读（无文字层） |
