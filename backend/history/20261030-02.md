# BE-20a / BE-33 / BE-32 / BE-21 / BE-02 后端安全与可追溯性

## 意图

为已跑通的上传到报告基线补齐最紧急的本地访问保护、加密材料口令控制、补件安全入库与状态机、审计检索和可读的数据库启动失败提示。

## 改动

- `config.py`、`helpers/security.py`：新增只从 `LOCAL_ACCESS_PASSWORD` 环境变量读取的本地 Bearer 口令校验；报告、模板、银行任务列表和全部写接口均受保护，健康检查与借款人状态查询保持可用。
- `routers/tasks.py`、`services/analysis.py`：以文件对象为维度统计加密 PDF 的失败口令次数；三次失败后返回 `E_LIMIT`，取消、失败和成功尝试均写审计，审计内容不含口令。
- `services/workflow.py`、`routers/tasks.py`：集中定义八态状态机；新增补件接口，仅允许 `NEED_SUPPLEMENT → PARSING`，只追加 `task_file`，并留审计。
- `routers/audit.py`、`main.py`：新增受保护的审计分页查询，支持按对象、操作人、动作和时间过滤。
- `db/session.py`：数据库初始化改到应用启动期；连接失败给出环境变量和 MySQL 状态的可读提示。
- `backend/tests/`、`requirements-dev.txt`：新增安全与状态机回归测试。
