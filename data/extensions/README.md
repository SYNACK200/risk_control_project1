# 独立扩展测试准备

adapters.py只面向纯模拟数据，不是正式契约、不是已批准存储替代方案。没有新增表/迁移，不调用OCR、不实现计息或判定，不触碰其他模块。

- DemoRateCatalog：调用方明确allow_demo=True，提供synthetic_only文档和带来源/单位/有效期/版本的记录；查询必须指定版本，不默认选择最新，不给真实利率或计算结果。测试0.0000仅虚拟值，不能用于业务；DA-05正式利率表、计息规则表和算法接口仍待PM/银行确认。
- append_ocr/read_ocr：测试用已脱敏OCR结果追加独立文件，包含文件ID、解析版本、页码、归一化坐标、置信度与内容SHA256；只新建UUID文件，不覆盖。只允许synthetic_only材料，目录由调用者事先保护。哈希用于损坏检测，不是签名，也不阻止目录管理员修改；并非生产不可篡改存储。
- 坐标归一化及字段命名仅内部测试协议，不冻结行内OCR接口。正式DA-18中间表、MinIO不可变策略、留存、脱敏与证据回查必须批准后再接入。文本扫描是启发式，真实客户OCR仍需批准的清洗流程。

验证：`python -B data/tools/test_extensions.py`。运行只在临时测试目录造模拟对象，不写数据库、不注册服务、不保存真实凭据。
