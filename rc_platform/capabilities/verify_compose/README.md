# verify_compose（五态组合）

能力名：`verify.compose` · 产出 `verification` · 依赖 `layer_file` + `layer_content` + 可选 `layer_ledger` / `layer_external`

只做两件事：把四层结果交给五态规则、把结果转成契约。**判据一行都不抄**——
抄一遍就等于又开一套口径，这是重构里最容易犯又最难发现的错。

## 可选层

账务层与外部层是 `optional_requires`：本行没接入时按「未执行」处理，
结论照出、该层 `skipped`、限制里写清，而不是让整单失败。

## 硬守卫

内容层缺原生检查对象时直接报错，不硬凑——成因区分（数据断 vs 识别不准）靠的就是那些检查对象，
凑出来的结论会把「字没认准」误判成「流水造假」。

## 测试

`tests/`：四层是否真的是独立能力、停用外部层仍出结论、同名契约换实现不改主干。
