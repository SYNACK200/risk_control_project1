# parse_v2（解析，自有实现）

能力名：`parse.layout_v2` · 产出 `statement` · 依赖 `document` + `layout`

按新版式切行切值：列边界来自锚点扩散长出的包络，切值用同一份几何，不再「边界一套、取值另一套」。

## 切行口径

一行里同时有日期和金额才算一笔；没有日期也没有金额的行，如果紧跟上一条明细，当作它的续行。
页脚（合计/小计/本页）与表头行会被剔掉。

## 取值口径

- 金额与余额：取列格里第一个能解析成数字的 token（列里可能混进别的字，例如微信把「支付方式」并进金额列）
- 方向：优先方向列（收/入/贷 → in，支/出/借 → out），其次看落在收入列还是支出列，最后看金额符号
- 缺日期写告警、缺金额写告警，但都不丢行

## 什么时候会跳过 / 失败

版式为空 → 抛错（由编排按 `degrade` 处理）；版式有区域但一行都没切出来 → 抛错。

## 测试

`tests/`：与旧解析逐笔一致（日期/方向/金额/余额）；`tools/parity` 覆盖 9 份样本。
