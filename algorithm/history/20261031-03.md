# 页眉字段抽取与内容层 C5 表头跨页一致

## 意图

C5–C10 判据 v1 定稿后按既定顺序先做第 1 步：补页眉字段（账号/户名/期间）并接上
C5。目标是跨页比对抬头能否对上，发现换页拼装；没有字段就 `skipped` 写原因，
掩码字段不硬判。阈值、C1–C4 与其他检查口径均未改动。

## 改动

- `ocr/models.py`：新增 `HeaderField`（值 + bbox + confidence）与 `PageHeader`
  （page_no、account_no、account_name、period_start、period_end、`is_empty`）；
  `ParseResult.headers` 默认空列表。
- `ocr/parse.py`：
  - 从表头上方逐行抽取页眉：`卡号/账号/帐号`、`户名/账户名/客户名称/户主/姓名`、
    期间（`--`、`至`、`到` 等分隔，允许两端带时分秒）。
  - 逐字抽取的 PDF（数字被拆成 `2 0 2 6`）先去掉空白再匹配；户名按原文本取到
    下一个空白，避免吞掉后面的期间。
  - 每个被解析的页都追加一条 `PageHeader`，没有抬头的续页记空对象，不猜。
  - `_transactions_from_pages`、`_parse_pdf_pages`、`_parse_with_plumber`、
    `_parse_ocr`、`_build_result`、`parse()` 全部透传 headers。
- `algo/content_layer.py`：新增 C5 `_check_page_headers()`。
  - 少于 2 页 → `skipped`「单页无可比项」；
  - 任一页抬头为空 → 整项 `skipped` 并写页码；
  - 账号/户名按掩码对齐，只比两边都未掩码的位，长度不同或全是掩码 → 该字段不可比；
  - 期间按起止日逐页比对；
  - 可比字段对不上 → `fail`，`Attribution(cause=data, action=stop)`，证据挂两页
    抬头 bbox；有字段不可比但其余一致 → `partial`；全部不可比 → `skipped`。
  - 低置信页眉字段（OCR）按不可比处理，不判 fail。
- `ocr/__init__.py`：导出 `HeaderField`、`PageHeader`。
- 测试：`test_parse.py` 补页眉抽取（逐页字段、带时分秒的期间、无抬头续页）；
  `test_content_layer.py` 补 C5 的 pass/fail/单页/缺页/全掩码/部分掩码/低置信；
  `test_verdict.py` 与 `test_content_layer.py` 的干净件夹具补两页一致抬头。
- 文档：`design.md` 更新字段可得性与首轮验收结果、C5 分级口径；`algo/README.md`
  内容层表补 C5；`chat.md`、`tasks.md` 同步进度。

真实件（脱敏副本，本机）：

```
icbc_desensitized.pdf  102 笔  C5 partial：账号 5 页一致；户名掩码不可比；期间未印
cmb_desensitized.pdf    30 笔  C5 skipped：第 2 页抬头未识别
wechat_desensitized.pdf  0 笔  C5 skipped：第 2、3、4、5、6 等页抬头未识别
```

三份均无 C5 `fail`，五态结论与改动前一致（工行/招行未发现异常，微信无法判定）。
工行 C5 为 `partial` 后内容层仍为 `limited`（C4 本来就 skipped），结论理由仍是
「已完成的核验未发现矛盾；部分检查不可算」。

## 遗留

- C6 参考号连续性、C10 重复记录 fail 分支仍缺 `reference_no` 字段，按判据 v1
  只会 `skipped` 或走提示分支。
- C7 时间分布、C8 金额形态、C9 语义匹配尚未实现（C7 只有工行件有 `trade_time`）。
- 招行/微信续页不重复抬头，C5 目前只比较到第 1 页；若后续要覆盖续页，需要
  版式模板说明抬头是否重复，不能靠猜。
- `headers` 尚未进入报告 JSON 或 `txn` 落库，C5 证据目前只到页码 + 抬头坐标。

## 裁决

- C5 只在可比字段上判 fail；掩码/缺失走 `partial` 或 `skipped`，不写「通过」。
- 续页没有抬头就如实记录为空，不用第 1 页值回填。
- 本轮改动全部留在工作区，未提交、未推送、未 `git pull`。
