# 样本集 v3：同参考号复制件，C6/C10 fail 进 eval

## 意图

C6（参考号连续性）与 C10（重复记录）的 fail 分支上一轮只有单测覆盖：三份真件
都没有参考号列，工行件的「序号」还被脱敏成 `00000`。为了让这两条分支走完整的
解析 → 内容层 → 五态链路，补一份带参考号列的合成件，并让评测能端到端断言。

选「整行复制一笔且参考号相同」而不是别的伪造形态，是因为它能同时验证两件事：
参考号列能被解析并挂到明细上；同号两笔完整明细时 C6 与 C10 都会 fail。

## 遗留

- 该件只能证明「同一参考号 + 同组字段齐全」这条路径通；如果复制行缺对手方或
  摘要，C10 会因该行不参与分组而漏判，只有 C6 能捕获（真件补测时同样现象）。
  含参考号的真件到位后仍要同时核这两点，不能拿合成件当真实件验收。
- 换利率、整份重排两类伪造仍未造：前者缺银行挂牌利率表，后者缺同版式真件基线。
- 合成样本与清单不入库；新环境需先 `python -m algorithm.algo.samples` 再评测。

## 裁决

- 伪造件要「只被目标检查抓到」：复制一笔时同步改写其后余额与页脚，避免 C1/C2/C3
  抢先 fail 掩盖 C6/C10 的效果；这也是判据里「重号是独立证据」的直接体现。
- 同步复制参考号是必要条件——只复制字段不给同号，按判据 v1 只能出 `hint`。
