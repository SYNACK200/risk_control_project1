# AL-34 标注导出转换层：坐标框直接进 parse()

## 意图

标注页导出的产物（`template-spec.md` v1：`page_size` / `match_rule` / `meta_boxes` /
`tables[].columns` 的 x/w）之前只有 `local_run.py` 做了一层临时兼容——按
`header_fingerprint` 与列顺序 zip 成 `field_map`，`parse()` 本身不认坐标框，
meta_boxes 完全丢弃。标注产物不能直接进解析，标注页与解析器之间差一层手工映射。

## 改动

- 新增 `algorithm/ocr/template_convert.py`：`convert_annotation(export, file_bytes=None)`。
  - 按 template-spec 第七节校验：T001–T009 阻断、W001–W005 提示；任一 T 错误返回
    `template=None`，只给 errors。T005 按“同一表格内重复列 / 同页重复框”执行，
    跨页同字段按第九节允许（抽取侧取首个非空）。
  - 列 → `field_map`：列框 x/w 按页面实际宽度换成点，在 `header_y` 附近找表头行；
    表头指纹命中 ≥ 一半时优先按指纹定位（标注页与实际版面纵向漂移时 header_y 会落到
    数据行）。列框与表头词按横向位置匹配，取词文本作别名；同一别名对应多列时改用列序号。
  - 无样本兜底：定位不到时，列数与 `match_rule.header_fingerprint` 一致则按顺序映射；
    必需列仍缺记 T003（「列未能定位表头」），不产出模板。
  - `meta_boxes` 中 `account_no`/`account_name`/`period` 转成 `Template.meta_boxes`，
    其余字段保留在标注中不消费（notes 说明）。
- `ocr/models.py`：新增 `MetaBox`；`Template` 增加 `meta_boxes` 与 `page_size`（均为可选，
  旧模板构造不受影响）。
- `ocr/parse.py`：
  - `parse()` 的 `template` 参数接受 v1 导出 dict，内部先转换；失败只返回带 T 码的
    warnings，不产出半份结果。
  - `_page_header()` 优先按标注框取账号/户名/期间（`_fill_header_from_boxes`），框内取不到
    再走原有文字标签；影像件词坐标是像素、与模板 pt 差数倍时自动跳过框，退回标签。
- `local_run.py` / `diagnose_s4.py`：`load_template(path, file_bytes)` 统一走转换层；
  旧版 `field_map` 模板保持原样。`local_run` 调用时把解密后的 PDF 传进去用于定位表头。
- `ocr/__init__.py`：导出 `convert_annotation`、`ConversionResult`、`MetaBox`。
- 测试：新增 `tests/test_template_convert.py`（20 项）覆盖完整导出转换与解析、dict 直喂、
  meta 框取页眉、几何优先于指纹顺序、无样本指纹兜底、旧版 passthrough、T001–T009 逐码、
  W002/W004/W005、JSON 往返；`tests/test_local_run.py` 的箱体模板用例改走转换层
  （无指纹改判 T009）。
- 文档：`ocr/README.md`、`template-spec.md`（新增“标注转解析模板”一节）、`design.md` C5 行、
  `tasks.md`、`chat.md`。

## 遗留

- 招行标注导出里 amount 与 balance 列框重叠 0.1pt（四舍五入到 4 位后仍擦边），按
  template-spec 判 W002；不影响解析，是否给容差要改规范，未动。
- 招行件标注页表头与脱敏重排版纵向差 47pt，靠指纹兜住；这属于“标注后原件重排”，
  不是转换层能消除的。若标注页和交付件版式不一致，仍需要人工确认。
- 起决定作用的是 `match_rule.header_fingerprint` 的文本与真实表头一致；指纹是别名
  （如「对方户名」对「对方名称」）时只能退回 header_y 直线定位，可能落到数据行。
- 页眉框只消费账号/户名/期间；开户行、期初期末、合计等仍在标注里，未做抽取。
- 没有指纹的 v2 导出现在记 T009 拒绝转换（按规范），旧的“按列序号兜底”已移除；
  自制的旧模板若没写指纹需要补上。
- 转换层不做反验（AL-36 的余额链/笔数校验只在外推时做）；是否需要转换后试解析一遍
  再出模板，待标注页联调时定。

## 裁决

- 标注导出格式以 `template-spec.md` v1 为准；T 码是阻断项，转换层不猜、不产半成品。
- 表头定位以列框几何为主、表头指纹负责选行；两者冲突时几何落列、指纹选行。
- `parse()` 接受导出 dict 是为了验收“标注导出后可直接喂 parse()”，转换逻辑仍只有一份
  实现（`template_convert.py`），`local_run` 不再自带映射。
