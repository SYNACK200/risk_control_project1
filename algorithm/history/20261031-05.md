# 参考号抽取、C6–C9 与 C10 fail 分支

## 意图

按 C5–C10 判据 v1 收尾：补 `reference_no` 字段，实现 C6 参考号连续性、
C7 时间分布、C8 金额形态、C9 语义匹配，以及 C10「同组且同参考号」的 fail 分支。

分工原则仍是「客观事实才 fail」：只有同一参考号出现在两笔完整明细才判数据断；
跳号/格式、夜间/同秒、金额形态、摘要矛盾全部只提示，不改五态；
没字段、没执行一律 `skipped` 并写原因，不写通过。

## 改动

- `ocr/models.py`：`Transaction.reference_no`（原件未印时为 None）。
- `ocr/table.py`：新增参考号别名「参考号/流水号/交易流水号/凭证号/业务编号/
  交易单号/交易编号」；不含「序号」——工行的「序号」是页内行号，不是一笔一号。
- `ocr/parse.py`：新建明细与续行合并时抽取参考号，续行只补空值不覆盖。
- `algo/content_layer.py`：
  - C6 `_check_reference_continuity()`：
    - 一笔一号门槛：≥3 个参考号、去重后 >1 个值；不足 → `skipped` 写原因。
    - 同一参考号出现在两笔完整明细（日期、金额都在）→ `fail` + 数据断归因。
    - 相邻同号且存在缺日期/金额的行 → `hint`「疑似续行未合并」，不判 fail。
    - 同号但行不相邻且字段缺失 → `hint` 需人工核对。
    - 格式不一致（位数/字符类型）与数字跳号 → `hint`；部分行缺参考号 → `partial`。
  - C7 `_check_time_distribution()`：
    - 无 `trade_time` → `skipped`「无交易时间，未核对」。
    - 时间非 `HH:MM:SS`、有时间但日期缺失 → `skipped` + 识别归因（转人工）。
    - 夜间 22:00–06:00、同日同 `HH:MM:SS` ≥2 笔 → `hint`，列出全部命中行。
    - 部分行无时间 → `partial`。
  - C8 `_check_amount_shape()`：整数金额占比、同额重复 TOP3（按绝对值）、
    分位尾数 0–9 分布、样本 <10 笔注明；恒为 `hint`（只出统计），不设阈值、
    不判 fail；无金额 → `skipped`。
  - C9 `_check_semantics()`：8 条明确矛盾规则全部只 `hint`；
    规则 1 排除「贷款利息/罚息/透支利息」；规则 7 的「个人」按 2–4 个汉字且
    不含机构词的启发式；摘要/方向/对手方缺失的规则写 skipped 原因，
    所有规则都跑不了 → 整项 `skipped`；命中 detail 写规则号与行号。
  - C10：新增 fail 分支——重复组内每行都有参考号且相同，并且参考号满足
    「≥3 笔、去重 >1」的一笔一号门槛 → `fail` + 数据断归因；
    参考号不足时维持 `hint`，措辞改为「参考号未抽取或不足以确认」。
  - `analyze_content()` 检查顺序改为 C1→C10。
- 测试：`test_content_layer.py` 补 C6（同号 fail、续行提示、格式/跳号、门槛、
  单值、缺失、部分覆盖）、C7（夜间、同秒、非法时间、有时间无日期）、
  C8（无金额、统计、小样本）、C9（利息命中、贷款利息排除、工资给个人、
  无规则可执行）、C10（同号 fail、参考号不足仍 hint）；干净夹具补 3 笔、
  参考号与时间。`test_parse.py` 补参考号列抽取。`test_verdict.py` 夹具同步。
- 文档：`design.md` 更新字段可得性、真件复跑结果与实现顺序；
  `algo/README.md` 内容层表补 C6–C9、改写 C10；`chat.md`、`tasks.md` 同步。

## 遗留

- 三份真件都没有参考号列：C6 的 fail 与 C10 fail 分支只有单测覆盖，
  需含参考号的真件再验，不能据此对外宣称已验证。
- C7/C8/C9 的提示线仍是 v1：C8 不带阈值、C9 规则表固定 8 条；
  升级或增删规则要升 `rule_version`，旧报告不回写。
- `hint` 只进 limitations，不进报告 evidence；前端若要跳转提示行需补契约字段。
- 工行模板 `channel=10` 列序号错位、AL-34 转换层、影像件/外部层等遗留同前。

## 裁决

- 参考号只认「一笔一号」：去重后只有一个值或不足 3 笔时不能拿来判重，
  宁可 skipped，也不把「整列同一个号」当成两笔重复。
- 金额形态只统计不设线：整数占比高可能是客户习惯，v1 不因此判 fail；
  等真件分布够了再定提示线并升版本。
- 语义规则只做明确矛盾：贷款利息、工资付给公司等正常业务不进提示。
