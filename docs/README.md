## 写文档的约定

1. **一个主题一份文档**，不要按日期堆（日期只用于「某次验收」这类留档）。
2. 新文档必须在上面登记，写清「什么时候该读它」。
3. 规范类文档（版本管理、报告契约、模板规范）改动要在 CHANGELOG 里体现。
4. 留档类文档过期不删，但要在本表标注它是历史记录。
5. 文档里的命令、路径、账号必须是**能直接复制执行的**。
