## 这一轮修掉的问题

### CSS 花括号不平衡（根因级）

`app.css` 里 570 个 `{` 对 569 个 `}`。`.trust-chip` 规则只写了一半：

```css
.trust-chip { font-size: 12px; padding: 2px 8px; border-radius: 999px;   /* 缺 background/color，缺 } */
```

这个未闭合块把之后**所有**规则包了进去，浏览器整段丢弃。受影响的是 `.inline-field` 和 `.infer-preview`/`.pv-cell`——表现就是多页预览 30 个格子挤成一坨（`10 219 319…`）、自定义字段输入框没边框。

补齐后花括号平衡 571 / 571，`getComputedStyle` 确认 `.infer-preview-grid` 的 `display` 从 `block` 变回 `grid`。

**以后每次改 CSS 都该跑这个自检：**

```python
assert css.count('{') == css.count('}'), f'{css.count("{")} vs {css.count("}")}'
```

### 列清单组件化时漏了两处

抽出 `ColumnFieldList.tsx` 时用了旧版 `className="column-row"`，漏了 `active` 类（点画布不高亮）和 `id`（自动滚动找不到目标）。已补回。
