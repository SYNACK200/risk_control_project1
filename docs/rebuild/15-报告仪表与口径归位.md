# 报告仪表、指标展开、口径说明归位

> 2026-11-14 · 分支 `rebuild/v1`
> 触发：使用者指出「单份报告没有仪表、字段点不开；指标口径/校验口径是只读字典却摆在参数栏」。

## 一、报告有仪表了

结论页顶部按「总分 → 四层 → 分区」三层铺开，数据全部来自报告 payload（`scores` / `trust` / `trend`）：

| 块 | 内容 | 数据来源 |
| --- | --- | --- |
| 总分卡 | 79 / 等级「一般」/ 计分方法原文（分区扣分制：每命中一条风险结论 −15…） | `scores.overall / grade_label / method` |
| 四层卡 | 载体层 70 limited、内容层 70 limited、账务层 70 limited、外部层 0 unavailable，各带得分条与权重 | `trust.layers` |
| 分区得分表 | 收入能力 85（25%，8/8）· 负债与还款 100（25%，8/8）· 资金与余额 40（25%，8/8，命中 LOW_BALANCE/NET_OUTFLOW/BALANCE_DECLINE/FAST_IN_OUT）· 异常行为 95 · 对方方与集中度 85 | `scores.domains` |
| 月度收支图 | 11 个月的收入/支出柱 + 净额虚线，横轴 21-05…22-03 | `trend` |

图表用 SVG 手写（`components/ReportCharts.tsx`），没有引图表库——图形只有三类，引一个几百 KB 的库不划算。
交易流水页另加「金额分布」：<1千 / 1千–1万 / 1万–5万 / 5万–20万 / ≥20万 五档，带笔数与占比条。

## 二、指标能点开了

指标页每行右侧「怎么看」，点开在该行下方展开：**口径原文**、**本次值**（不可算时说明是缺输入还是本期无数据）、
**口径版本**（历史报告按当时版本解释），以及一条「看这一项的标准口径说明」跳转。

口径原文来自报告 payload 的 `metrics[].note`，例如 A02 月均收入：「A01 ÷ 实际覆盖 10.3226 个整月
（314 天，首末月按当月天数折算）」。这是**这次解析实际用的分母**，不是抽象定义——比字典里的说明更有用。

## 三、口径说明归位

问题：指标口径、校验口径是**只读字典**，却被放在「参数」栏，与能改的风控参数、OCR 路由并列。
参数栏的语义应当是「能调的东西」，字典混在里面会被当成可改项。

处理：两者合并为一页 `/bank/glossary`「口径说明」，放在**系统**组（与操作审计、账号同级），
参数栏只剩「风控参数」。报告里点开指标的那条链接就指向这里；旧路由 `/bank/metrics`、`/bank/verifications` 仍可直达。

侧栏现在：受理与报告（任务与报告）· 模板（模板库、标注）· 参数（特征 Lab、风控参数、客户与账户、OCR 路由）· 系统（口径说明、操作审计、账号）。
