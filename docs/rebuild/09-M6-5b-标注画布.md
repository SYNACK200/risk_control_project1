# M6-5b：标注画布（关键词定位 + 版面往下扩散）

> 日期 2026-11-11 · 分支 `rebuild/v1`

## 设计前提（用户定调）

**模板不再记死坐标。** 模板只声明「我需要哪些列」（卡号、交易日期、金额……）；
位置由系统在新文件上现找：

1. 关键词在文字层里定位（卡号可能出现在表头单元格，也可能出现在「卡号：6222…」这类说明行）；
2. 版面分析把「文字所在的框」定下来（同一行 / 同一列）；
3. 顺着表格的排列往下扩——下面同一列的框就是这个字段的值。

所以画布上画出来的不是「我画的框」，而是**系统认出来的列带 + 它往下捡到的单元格**。
人的工作变成三件小事：认错字段名就改、列带偏了就拖、漏了就用关键词补一条。

## 交付

| 层 | 内容 |
| --- | --- |
| 后端 | `capabilities/layout/inspect.py`：`inspect(data)` 整页扩散报告、`spread(data, keyword)` 单关键词扩散 |
| API | `GET /api/v1/lab/inspect`、`/lab/spread`、`/lab/sample-file`（8020） |
| 前端 | `/bank/annotate`：pdf.js 渲染原页 + 列带/单元格叠加层 + 拖拽与手柄 + 关键词加列 + 保存 |

### 三条防「不规整数据」的规则（都在 `inspect.py` 里）

1. **表头行取「包含 header_y 的那一行」**，不是「表头之上第一行」——页面顶部还有行名/账号行，取错会把表头自己当成第一个数据格。
2. **页脚收手**：遇到「本页/合计/小计/打印…」立即停止，否则「本页交易笔数：3」会被当成最后一笔金额。
3. **行距突变收手**：连续行距的中位数突然放大 3.5 倍以上，说明表格段落结束（换页眉、换区块）。

## 验收（真服务 + 真 PDF）

GET /lab/spread?sample=clean/icbc.pdf&keyword=余额 → 2 条列带，各 3 格 ['13,200.00',…] / ['24,399.50',…]
GET /lab/sample-file?sample=clean/icbc.pdf → 200，433,945 字节

浏览器实测（1440×805）：`/bank/annotate` 渲染出 CCB 流水页，6 条列带与 PDF 上的真实列对齐，
红框标出每个被捡到的单元格；右栏列出 6 列（txn_date 40–75、summary 170–184……）。
点「保存为模板」→ 生成 **CCB v3 草稿**，落库 6 列归一化列带
（txn_date x=0.050 w=0.044、summary x=0.212 w=0.018、counterparty x=0.375 w=0.035、amount_in x=0.537 w=0.038）。

## 技术细节

- pdf.js 走动态 `import()`：银行侧主包 45.9 kB，pdf 单独 329 kB 分块，只在打开画布时加载。
- worker 用 `workerPort` 而不是 `workerSrc` 字符串——`?url` 导入在 dev/prod 行为不一致，实测报 `Invalid workerSrc type`。
- StrictMode 下 effect 会跑两次，pdf.js 不允许同一 canvas 并发渲染：先 `cancel()` 上一次再开始，并吞掉 `RenderingCancelledException`。

## 还没做

- **扫描件（无文字层）**：一条列带也扩不出来，页面上已明说要走 OCR；OCR 通道（`layout/ocr_words.py`）存在但没接到画布。
- **多表格区**：一页里有多个表（明细表 + 汇总表）时，目前只输出一个区域。
- **自动字段命名**：关键词→字段靠 `guessField` 的规则猜，猜错要人工改；真正的语义匹配（表头词 → 规范字段）还没做进画布。

## 再修正（用户问「原始的 pdf 呢」）

问题：标注页之前只能从 9 个合成样本里挑，既不能打开自己的文件，也不能打开已受理任务的原件；
而且默认缩放下 800×1000 pt 的流水页正文只有 7px，看着像「只有几条竖线没有底版」。
解决状态：已修。三处改动：
① 来源三选一——本地上传 PDF、按已受理任务取原件（新接口 `POST /lab/inspect-file`、`/lab/spread-file`，任务侧复用 `GET /tasks/{id}/file`）、内置样本；
② 画布顶部固定显示「原件：名字 · 第 x/y 页 · 尺寸 pt · 缩放%」，并提供 −/+/适应宽度 与翻页；
③ 默认缩放 1.35，列带宽度按捡到的单元格包络扩出、高度只画到最后一个单元格（原来画到页底，像这一列一直空着）。

证据：`clean/ccb.pdf` 第 1 页渲染出「银行账户交易明细 / 交易日期 / 摘要 / 对方户名 / 收入金额 / 支出金额」与 6 行数据，
6 条列带与真实列对齐；任务 #151 原件同样渲染，`已分析：2 页，第 1 页认出 6 条列带`。
接口实测：`inspect-file` → 2 页 6 列带；`spread-file(keyword=余额)` → 两页各 3 格。
