## 归并后修掉的 4 个可用性问题（改动都在前端）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 原件左侧被切掉、框和字看着对不上 | `.pdf-stage-wrap` 用 flex 居中，内容比容器宽时溢出部分跑到左边且滚不回去 | 改为 block 布局 + surface `margin: 0 auto`，可正常滚动 |
| 画布位图与叠加层可能有 1–2px 漂移 | canvas 后备缓冲按 dpr 放大，CSS 尺寸与 surface 不完全一致 | canvas/img 强制 `width/height: 100%`，与 surface 同框 |
| 正文太小、框线把字盖住 | 默认缩放 1.1，800pt 页面正文只有 8px | 默认 1.6；框向外扩 2px（`calc(… - 2px) + 4px`），边框不再压字 |
| 列带比实际值窄（「交易时间」4 字 vs「2026-10-01」） | 宽度取自表头词或预读边界 | 显示宽度取「列宽 ∪ 实际读到格子的包络」，只影响显示，保存仍是 col.x/col.w |
| 侧栏第三列显示成「交易日期」两次 | 模板里存的是 `counterparty`，下拉候选只有 `counterparty_name`，select 找不到就显示第一项 | 载入模板时用 `canonicalField` 归一化；下拉对未知字段也原样列出 |
