## 目标结构

```
web/
  index.html
  vite.config.ts          # base: '/'，dev 代理 /api 到 8010
  src/
    main.tsx
    App.tsx               # 路由：公开页 / borrower / banker，按角色懒加载分包
    api/
      client.ts           # 统一的 fetch 封装：base、token、错误码、超时
      errors.ts           # 错误码 -> 中文文案（三端唯一来源）
    auth/
      store.ts            # token/user 的读写与过期判定（唯一一份 localStorage 逻辑）
      guards.tsx          # RequireRole 组件
    ui/                   # 按钮/表格/空态/加载骨架/对话框
    pages/
      public/{Landing,Login,Register}.tsx
      borrower/{Upload,Progress}.tsx
      banker/{Layout,TaskList,Report,Annotate,TemplateList,TemplateDetail,TemplateLayout,
              ImportTemplate,Thresholds,MetricDefs,VerificationDefs,Entities,Dashboard,
              OcrRouting,Users,Audit}.tsx
  dist/                   # 构建产物，后端挂到 / 与 /app /bank 的兼容跳转
```

## data 模块处置

| 目录 | 处置 | 理由 |
| --- | --- | --- |
| `data/privacy.py`（脱敏） | 并入 `rc_platform/capabilities/privacy/` 作为能力 | 脱敏是每次导出都要过的关口，应该是能力而不是脚本 |
| `data/retention.py`（留存干跑） | 并入 `rc_platform/adapters/retention.py` | 保留策略属数据层，但接口要能被 API 调用 |
| `data/core/schema.sql`（schema 权威） | 与 `rc_platform/migrations/` 合并成唯一 schema 权威 | 现在两套表定义（backend models + data core），必须收成一套 |
| `data/v2/`（实验线，importlib 加载 backend models） | 冻结，不迁 | 它是上一个会话的探索分支，已不产生新结论 |
| `data/bootstrap/*.ps1`、`data/evidence/` | 随封存版本冻结 | 装机脚本与验收留档属于历史交付物，不是运行期代码 |
