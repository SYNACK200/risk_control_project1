# 模板链路打通记录

> 2026-11-21 · 分支 `rebuild/v1` · 起因：用户反馈「模板界面无法载入新的模板」

## 一、先查清事实（不是猜）

| 检查 | 结果 |
| --- | --- |
| 后端三个入口 | `POST /templates/preview-draft` 200（读出 6 笔）、`POST /templates/save-from-canvas` 200（落库并启用）、`POST /templates/import` 200 —— **接口本身没坏** |
| 数据库模板状态 | 8 份全是 `disabled`，0 份 `enabled`、0 份 `draft` —— 「在用」页签必然为空 |
| 页面过滤逻辑 | 过滤正确：`在用=enabled / 草稿=draft / 已停用=disabled` |

结论：不是「载不进来」，而是（1）库里没有一份启用中的模板，页面只显示「当前筛选下没有模板」，
让人以为功能坏了；（2）新标注默认存成草稿，「草稿不会被解析采用」这条规则用户不知道；
（3）标注页的保存按钮在右栏底部，要滚过整列才能看到，而且保存前必须先选银行——
银行没选时点保存只弹一句「请先在右侧第二步选择银行」，用户找不到那一步。

## 二、改了什么

1. **模板库空状态给出路**（`TemplatesPage.tsx`）
   不再只说「没有模板」，而是报出各栏数量（在用/草稿/已停用/回收站）+ 四个按钮
   （去看草稿 / 去看已停用 / 标注一份新模板 / 导入 JSON）+ 一句规则说明
   「模板只有在用才会被解析采用：新标注保存后是草稿，点启用才生效」。

2. **保存按钮搬到顶栏**（`AnnotatePage.tsx`）
   顶栏常驻「仅存草稿 / 保存并启用」，与右栏底部那对按钮共用同一个处理函数。
   右栏可滚动，保存区经常在屏幕外——这是「点了没反应」的直接原因。

3. **载入样本自动带出银行**（`AnnotatePage.tsx`）
   内置样本名就是银行代码（`clean/ccb.pdf` → CCB），未选银行时自动填上。
   以前卡在「请先选择银行」，现在载入样本后可直接一键保存。

4. **保存区里补一个银行下拉**（`StepSidebar.tsx`）
   同一份状态，避免「填银行」和「保存」隔着一整屏。

5. **模板匹配真正接进链路**（`tasks.py` + `template_match.py`）
   上传选模板原来只按 `bank_code + enabled` 取第一条，同银行多版式会互抢，
   T9 写的匹配器根本没被调用。现在：
   - `doc_headers_from_pdf()`：从前两页收集「像表头」的词（真实件的第一页常常是账户信息，
     按行取会取空）；实测建行真件得到 `摘要 / 交易日期 / 交易金额 / 账户余额 / 对方账号与户名`
   - `header_similarity()`：包含关系也算命中（`账户余额` ≈ `余额`），并把老模板
     只存 `field_map`（键是 `txn_date` 这类）的情况映射回中文表头
   - `select_template()`：候选先按 bank_code 过滤，再按 layout_hash → 表头相似度取最佳
   - 结果写入 `check_result.template_match`：`by / score / doc_headers`，能复盘为什么用了这一版
   - 阈值从 0.6 降到 0.35，依据是实测：建行真件 vs 它自己的模板 = **0.444**；
     跨银行虽然也能到 0.2~0.5（表头词通用），但候选已按银行过滤，阈值只在同银行多版式间取舍

## 四、还没做的

1. **同银行多版式**这条路径没有真实双版式样本可验：目前 `publish` 会把同银行其它版本停用，
   所以正常数据里同银行只有一份启用模板；匹配器真正发挥作用的场景是历史数据里出现多份
   （例如停用后未清理）。要不要允许多份同时启用，是个产品决策，等你定。
2. **前端只做冒烟**：保存/加载/空状态都点过，但没有逐页核对跨页续页版式的保存结果。
3. `T8`（点表头定列）与 `F9`（实体页大改版）仍未做，与本次无关。
