# 模板页「智能字段分析建模板」专项修复说明

## 1. 功能设计（对应需求）
面向银行后台人员在 **模板库页面（`/bank/templates`）** 直接调用 Python 模板分析算法，只需上传银行流水样例 PDF 并输入两类需要解析的字段：

1. **短字段（就近匹配，Short Fields）**
   - 适用场景：卡号/账号、户名、起止日期、开户行、币种等页眉单值字段。
   - 算法实现（`backend/services/template_analyzer.py` → `match_short_fields`）：
     - 自动定位明细表头行上方的页眉区，避免误命中明细交易行；
     - 锚点词模糊匹配（支持多别名、冒号归一化、1-编辑距离容错）+ 标题噪音过滤（防止「个人活期账户全部交易明细」等页面大标题截胡）+ 候选打分择优；
     - 三级就近提取：**同行粘连**（如 `账号:6217...`）→ **右侧就近连续词合并**（遇大间隙或下一个标签自动停止）→ **正下方就近匹配**；
     - 输出匹配值、匹配方式与归一化坐标框（`layout.meta_boxes`）。

2. **标题字段（版式分析，Header Fields）**
   - 适用场景：交易日期、摘要、交易金额/发生额、账户余额、对方户名等明细表列字段。
   - 算法实现（`backend/services/template_analyzer.py` → `analyze_header_fields`）：
     - 全页按行聚类 + 表头行评分定位（要求至少命中 2 列并避开页眉）；
     - 基于**整行全部表头词**的相邻间隙切分列边界，防止跨列串读；
     - 表头下方数据行投影（自动在页脚/合计行处截断），统计每列命中行数与样例值，产出前 15 行结构化试解析预览；
     - 生成符合项目统一规范的 `field_map` 与 `layout`（含 `page_base: 0`、`layout_hash`、`tables[0].area/headerY/columns`、`meta_boxes`）。

3. **Python 底层库策略**
   - 优先使用 **PyMuPDF (`pymupdf` / `fitz`)**（速度最快、与项目现有 PDF 渲染管线一致）；
   - 若环境未安装 PyMuPDF，自动回退到 **`pdfplumber`**（纯 Python 词坐标提取，零外网依赖）。

## 2. 本包包含文件（按项目相对路径覆盖即可）
- `backend/services/template_analyzer.py`（新增：短字段就近匹配 + 标题字段版式分析引擎）
- `backend/routers/templates.py`（新增 `POST /api/v1/templates/analyze-fields`，支持试分析预览与一键入库/启用）
- `web/src/api/banker.ts`（新增 `analyzeTemplateFields` 及相关 TypeScript 类型）
- `web/src/pages/banker/TemplatesPage.tsx`（模板库页新增「智能字段分析建模板」交互面板、字段表格编辑、分析结果与试解析预览、一键保存草稿/启用与跳转画布微调）
- `tests/test_template_field_analyzer.py`（新增：建行/广发/工行真实与合成样例 PDF 回归测试）

## 3. 本地部署与验证步骤
1. 解压覆盖到项目根目录；
2. 后端验证：`python -X utf8 -m unittest tests/test_template_field_analyzer.py -v`；
3. 前端重新构建：`cd web && npm run build`（或开发态 `npm run dev`）；
4. 启动后端后访问「模板库」页面，点击顶部「智能字段分析建模板」，上传任意银行流水 PDF 样例即可运行算法、查看短字段与标题字段解析结果并一键保存为模板。
