# 智能风控 · 信贷项目 第四批修复说明（B1 / B2+F7 / T14 / B14 / F14）

本次修复覆盖第四批「架构收口与 P2 收尾」任务，共新增 **3 个模块**、修改 **14 个源码文件**（合计 **17 个文件**）。同时额外打包了**全量合并覆盖包（`全量修复合并包_第1至4批.zip`）**，包含第 1 至 4 批全部去重后的修复文件，方便你一次性覆盖部署。

## 一、本批修复明细

- **B1（`rc_platform` 接入主解析链路）**：
  - `backend/services/analysis.py` 引入 `PIPELINE_BACKEND` 环境变量开关（`legacy` / `rc_platform`），并在显式启用 `rc_platform` 或旧版解析产出 0 笔的 PDF 场景下，自动调用 `rc_platform.capabilities.layout.detect`（锚点扩散）+ `parse_v2.table_reader` 兜底解析，结果中记录 `pipeline_backend`。
- **B2 + F7（任务队列接口与银行侧可视化监控页）**：
  - 新增 `backend/routers/queue.py`（挂载于 `/api/v1/queue`，需银行侧权限），提供 `GET /queue/stats`（排队/运行/失败/完成与进程池占用）、`GET /queue/jobs`（排队位次、当前阶段、失败码）、`POST /queue/jobs/{task_id}/retry`（失败重试并写审计）与 `POST /queue/jobs/{task_id}/cancel`（取消排队并写审计），并在 `backend/main.py` 注册。
  - 新增 `web/src/pages/banker/QueuePage.tsx`，在 `web/src/api/banker.ts` 补齐队列 API 封装，并在 `BankerApp.tsx` 侧栏新增「任务队列（`/bank/queue`）」入口，支持每 5 秒自动刷新、一键重试与取消。
- **T14（模板列表使用统计）**：
  - `backend/routers/templates.py` 的 `list_templates` 聚合每个模板的历史任务数 `tasks_total` 与完成率 `success_rate`；`TemplatesPage.tsx` 新增「使用统计」列。
- **B14（上传体积上限、看板风险命中去重与报告多版本保留）**：
  - `backend/routers/tasks.py` 在 `create_task` 中强制校验 `len(data) > MAX_UPLOAD_BYTES` 并返回 `413 E_LIMIT`。
  - `backend/routers/dashboard.py` 在单个任务内对 `risk_hits` 与 `conclusions` 按规则 `code` 去重后再计入 `hit_counter`，消除双倍计数。
  - `backend/services/task_runner.py` 移除重复删除 `Report` 的冗余语句，改为按 `max(Report.version) + 1` 递增版本号保留历史报告。
- **F14（权限守卫、分包边界、审计分页与细节收口）**：
  - 新增 `web/src/lib/banks.ts` 抽离公共 `BANK_OPTIONS`，`UploadPage.tsx` 不再反向依赖银行侧 `annotate/types.ts`，恢复按角色分包边界。
  - `BankerApp.tsx` 为 `/bank/audit` 与 `/bank/users` 增加前端管理员守卫；`LandingPage.tsx` 修正已登录借款人点击「银行员工」误跳回 `/app` 的问题；`LoginPage.tsx` 补充「忘记密码请联系管理员重置」指引；`AuditPage.tsx` 补齐 `limit/offset` 翻页与动作详情筛选；`web/src/api/lab.ts` 的 `fetchSampleBytes` 改用统一 `requestBlob`。
