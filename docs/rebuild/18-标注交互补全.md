# 标注画布：单值可拖、列带最小宽度、聚焦模式

> 2026-11-14 · 分支 `rebuild/v1` · 对应「请解决你列出的问题」

## 1. 单值框可以拖了

之前只有「列」能拖，单值（卡号/户名/开户行/账户类型）靠标签自动定位、偏了只能删掉重来。

现在：
- **拖动**整个紫框移动位置；
- **右侧 / 底部 / 右下角**三个手柄改宽高；
- 右栏展开后还有精确输入：位置 x、y 与宽、高（单位 %，步长 0.5）；
- 拖动或选中时该框高亮，其余变淡。

坐标全程用 0-1 比例（与模板 `meta_boxes` 同口径），保存时不再需要换算。

## 2. 列带最小宽度

问题：表头比数据短时（如「摘要」两个字、数据是「工资/消费/转账」），框看起来贴着一串数字，
不像在框「这一列」。

处理：渲染时给列带一个最小宽度（页宽 3%），并以读取区域中心对齐。**保存的仍是真实读取范围**，
所以不影响识别，只影响看起来是否像「一列」。

## 3. 聚焦模式

列多的时候框互相挨着，看图得放大。现在点右栏任意一列的标题（或点画布上的框），
该列高亮、其余列与单值全部淡到 25%；再点同一列取消。

## 验证

| 项 | 结果 |
| --- | --- |
| 单值手柄 | 紫框右上/右下出现手柄方块；拖动后位置与保存值同步（0-1 比例） |
| 聚焦 | 点「摘要」后：该列 `band selected focused`，其余 5 列与 4 个单值 `dim`（截图可见） |
| 最小宽度 | 「摘要」框从 18pt 扩到页宽 3%（24pt）并居中，肉眼不再贴着数字 |
| 构建 | `tsc -b` 0 错误，构建通过 |
| 回归 | 本轮只改前端渲染与交互，后端与解析未动（上一轮 parity 10/10） |

## 还没做的

1. 聚焦只能选一列，没有「只看单值」或「隐藏框只看原文」的开关。
2. 拖动没有撤销（拖偏了只能再拖回或改数值）。
3. 手柄只给「右/下/右下」，没有四边四角齐全（拖左边界要反过来算宽度，暂未做）。
