## 二、为「能在本机跑通」做的三处非业务改动

1. `tests_batch2_b3_f6.py` 的 `ROOT` 同样写死作者沙箱绝对路径 → 改为按文件位置推导。
2. 同一脚本用空模块顶替 pymupdf → 改为「确实缺 pymupdf 才装桩」，否则会把真模块盖掉。
3. `PdfPageCanvas.onPasswordRequired` 的签名从 `() => void` 放宽为 `(wrong?: boolean) => void`，
   并在口令错误时传 `true`。F4 在报告页里按这个参数区分「第一次要口令」与「口令不正确」，
   而组件侧原来没有这个参数，类型对不上（tsc 报 TS2322）。

改完后专项 6/6 通过（原先是 0 过 6 败，全是路径与桩导致的假失败）。
