## 三、报告页（最需要收敛的一页）

现状：`结论版 / 明细版` 两个视图 + 5 个 tab，其中 `结论与评分` 与「结论版」语义重复。

目标：

```
/bank/report/:id?view=conclusion|detail&tab=verify|metrics|evidence|txns

结论视图（默认）：结论 + 真实性得分 + 综合评分 + 四层仪表 + 一票否决警示 + 口径摘要
明细视图：核验与自检 / 40 项指标 / 证据与原件定位 / 交易流水明细
```

规则：

1. `结论与评分` 这个 tab 取消，内容并入结论视图
2. 打印 / 存 PDF 自动回结论视图（防泄密，沿用现有逻辑）
3. URL 可分享：`?view=detail&tab=metrics` 直接打开对应位置
4. 指标点开的解释面板（`MetricExplain`）一行不改：计算公式 / 所需输入 / 口径说明 / 关联分布图

## 五、样式令牌（FE-102 的规格）

`web/src/styles/tokens.css` 只放变量，页面不许写裸值：

| 类别 | 变量 | 值 |
| --- | --- | --- |
| 主色 | `--c-primary` `--c-primary-weak` `--c-primary-ink` | `#2f6fed` / `#eaf1ff` / `#1e40af` |
| 语义 | `--c-ok` `--c-warn` `--c-danger` `--c-muted` | `#0f766e` / `#b45309` / `#b91c1c` / `#6b7280` |
| 底与线 | `--c-bg` `--c-surface` `--c-line` | `#f6f8fc` / `#ffffff` / `#e5e7eb` |
| 间距 | `--sp-1` … `--sp-6` | 4 / 8 / 12 / 16 / 24 / 32 px |
| 圆角 | `--r-sm` `--r-md` `--r-lg` | 6 / 10 / 14 px |
| 字号 | `--fs-xs` … `--fs-2xl` | 12 / 13 / 14 / 16 / 20 / 26 px |
| 阴影 | `--sh-1` `--sh-2` | 卡片 / 浮层 |

验收：`grep -rn '#[0-9a-fA-F]\{6\}' web/src/pages | wc -l` 降到 20 以内；剩下的必须是业务语义色（风险红等），并在注释里写明为什么不能用令牌。

## 七、做的时候的边界

1. **只搬不改**：页面内部逻辑这一轮不动，只改归属、路由、页头、样式变量
2. **不删文件**：旧页面组件保留，用重定向接住；删文件放到 W48
3. **每搬一页跑一次** `cd web && npx tsc -b`，红了立刻回退这一步
4. 报告页与标注画布是最贵的两个页面，改动后必须手工打开 5 个报告 + 做一次标注保存验证
