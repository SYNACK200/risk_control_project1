## 三、报告页（最需要收敛的一页）

现状：`结论版 / 明细版` 两个视图 + 5 个 tab，其中 `结论与评分` 与「结论版」语义重复。

目标：

```
/bank/report/:id?view=conclusion|detail&tab=verify|metrics|evidence|txns

结论视图（默认）：结论 + 真实性得分 + 综合评分 + 四层仪表 + 一票否决警示 + 口径摘要
明细视图：核验与自检 / 40 项指标 / 证据与原件定位 / 交易流水明细
```

规则：

1. `结论与评分` 这个 tab 取消，内容并入结论视图
2. 打印 / 存 PDF 自动回结论视图（防泄密，沿用现有逻辑）
3. URL 可分享：`?view=detail&tab=metrics` 直接打开对应位置
4. 指标点开的解释面板（`MetricExplain`）一行不改：计算公式 / 所需输入 / 口径说明 / 关联分布图
5. 页签键固定为 `verify` / `metrics` / `evidence` / `txns`；`view` 缺省或写错一律按结论视图，`tab` 写错按 `verify`
6. 资金全景（`InsightSection`，由交易明细算出的收支/分类/极值）放在结论视图，但标 `no-print`：屏幕上看得到，打印件里不出

## 五、样式令牌（FE-102 的规格）

`web/src/styles/tokens.css` 只放变量，页面不许写裸值：

| 类别 | 变量 | 值 |
| --- | --- | --- |
| 主色 | `--c-primary` `--c-primary-weak` `--c-primary-ink` | `#2f6fed` / `#eaf1ff` / `#1e40af` |
| 语义 | `--c-ok` `--c-warn` `--c-danger` `--c-muted` | `#0f766e` / `#b45309` / `#b91c1c` / `#6b7280` |
| 底与线 | `--c-bg` `--c-surface` `--c-line` | `#f6f8fc` / `#ffffff` / `#e5e7eb` |
| 间距 | `--sp-1` … `--sp-6` | 4 / 8 / 12 / 16 / 24 / 32 px |
| 圆角 | `--r-sm` `--r-md` `--r-lg` | 6 / 10 / 14 px |
| 字号 | `--fs-xs` … `--fs-2xl` | 12 / 13 / 14 / 16 / 20 / 26 px |
| 阴影 | `--sh-1` `--sh-2` | 卡片 / 浮层 |

上表是规格；`tokens.css` 里另外落了这些派生令牌，同样是「只放变量」的一部分：

| 类别 | 变量 | 用途 |
| --- | --- | --- |
| 主色 | `--c-primary-hover` `--c-primary-line` | 按钮悬停 / 主色描边 |
| 语义色五件套 | `--c-ok` `--c-warn` `--c-danger` 各带 `-ink`（深文字）`-bright`（亮色）`-bg`（浅底）`-line`（浅底描边） | 提示条、徽标、状态点都从这里取 |
| 中性 6 档 | `--c-neutral-1` … `--c-neutral-6` | `--c-ink` `--c-muted` `--c-line` 是其中三档的别名 |
| 填充 | `--c-fill` `--c-line-strong` `--c-bg-soft` | 胶囊底 / 虚线框 / 近白底 |
| 画布标注 | `--c-accent-area*` `--c-accent-single` `--c-accent-cell` `--c-focus-bg` | 表格区（紫）/ 单值框（青）/ 单元格（红）/ 定位行高亮 |
| 登录侧栏 | `--c-navy-*` | 深色底专用 |

带透明度的颜色一律写 `color-mix(in srgb, var(--c-primary) 12%, transparent)`，不从色值里拆 rgb，所以**改主色只改 `--c-primary` 一处**。

验收：`grep -rn '#[0-9a-fA-F]\{6\}' web/src/pages | wc -l` 降到 20 以内；剩下的必须是业务语义色（风险红等），并在注释里写明为什么不能用令牌。
补充口径：`app.css` 与 `tokens.css` 里不出现裸 `#` 色值与 `rgba()`；间距、圆角、字号只要求**新增或改写的规则**用令牌，存量规则里的像素值不在本周范围。

## 七、做的时候的边界

1. **只搬不改**：页面内部逻辑这一轮不动，只改归属、路由、页头、样式变量
2. **不删文件**：旧页面组件保留，用重定向接住；删文件放到 W48
3. **每搬一页跑一次** `cd web && npx tsc -b`，红了立刻回退这一步
4. 报告页与标注画布是最贵的两个页面，改动后必须手工打开 5 个报告 + 做一次标注保存验证

### 遗留给 Lead 裁决的两点

1. **「术语」页签没有数据源。** 后端目前没有任何术语/glossary 接口；现有的 `GlossaryPage` 实际是「口径说明」，内容是指标口径与校验口径的只读重复，并且自带两个内层页签。按「复用现有三页组件、不重写表格」的要求，它先原样挂在术语页签下，于是会出现页签套页签。要么后端补一个术语接口，要么把口径中心收回两个页签——需要定。
2. **`/bank/lab` 的归属与后端验收清单冲突。** 本章要求它重定向到 `/bank/features`（前端 A-3 按 12 条旧路由验收），但 `00-验收清单.md` 的 B-11 写的是「打开 `/bank/lab` 旧页，目录与试算仍可用」。本实现按本章执行：`LabPage.tsx` 文件保留未删，试算改由特征平台页跳到 Lab 自带的 `/ui`。B-11 的验法需要同步改。
