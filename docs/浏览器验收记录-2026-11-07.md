## 发现的问题

### 1. PDF 中文不渲染（已修，未验证通过）

「改框画范围」页的画布只有表格线、印不出汉字。控制台：

```
Warning: loadFont - translateFont failed: "UnknownErrorException: Ensure that the `cMapUrl` and `cMapPacked` API parameters are provided."
```

原因：`pdfjs.getDocument` 没传 `cMapUrl`/`cMapPacked`，CID 中文字体加载不了。

已做：`public/cmaps/` 放入 168 个 `.bcmap`（`/bank/cmaps/UniGB-UCS2-H.bcmap` 实测 200）；`getDocument` 增加 `cMapUrl=(BASE_URL)+'cmaps/'`、`cMapPacked=true`。

**仍未通过**：重新加载后同样 4 条告警，截图与修复前 sha256 相同。已排除：路径 200、产物 JS 含 cMapUrl、worker 配置、服务端引用最新 hash。未排除：浏览器缓存旧 bundle。

### 2. 阈值页输入框显示 0（未定位）

`#/thresholds` 里「收入波动上限」输入框显示 **0**，但接口返回：

```
values.income_cv_high = 0.40
def: income_cv_high | default= 0.5 | min= 0.05 | unit= 倍
```

页面另外两列「0.5」（默认值）与「0.05 ~ 3」（范围）都是对的，只有当前值变成 0。

已排除：`asText()`（String(0.4) = "0.4"）、`draft` 初始化、CSS 宽度（产物里 `.thr-input{width:96px}` 且无覆盖规则）。

**根因未定位**。下一步建议：在 `ThresholdsPage` 里打印 `Object.entries(payload.values)`，确认浏览器侧拿到的到底是不是 0.4。

「构建通过 + 接口 200」**不等于**页面可用。这一轮验收就抓出两个前者发现不了的问题。
后续每次交付前端改动，都应当跑一遍 CDP 验收。
