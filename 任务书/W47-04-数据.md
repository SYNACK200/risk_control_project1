### DA-101 · 两张表的模型 + 参考 DDL（P0，1 天）

**交付 1：`lab_service/models.py`**

```python
from datetime import datetime
from decimal import Decimal

from sqlalchemy import DateTime, Index, Integer, Numeric, String, UniqueConstraint, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column


class LabBase(DeclarativeBase):
    pass


class LabRun(LabBase):
    __tablename__ = "lab_run"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    run_id: Mapped[str] = mapped_column(String(40), unique=True, nullable=False)
    request_hash: Mapped[str] = mapped_column(String(64), nullable=False)
    client_ref: Mapped[str | None] = mapped_column(String(120))
    carrier: Mapped[str | None] = mapped_column(String(20))
    bank_code: Mapped[str | None] = mapped_column(String(16))
    row_count: Mapped[int] = mapped_column(Integer, nullable=False, default=0)
    catalog_version: Mapped[str] = mapped_column(String(16), nullable=False, default="1.0")
    status: Mapped[str] = mapped_column(String(16), nullable=False, default="succeeded")
    created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now(), nullable=False)
    expires_at: Mapped[datetime] = mapped_column(DateTime, nullable=False)
    __table_args__ = (
        Index("idx_request_hash", "request_hash"),
        Index("idx_client_ref", "client_ref"),
        Index("idx_expires_at", "expires_at"),
    )


class LabRunValue(LabBase):
    __tablename__ = "lab_run_value"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    run_id: Mapped[str] = mapped_column(String(40), nullable=False)
    code: Mapped[str] = mapped_column(String(40), nullable=False)
    value_decimal: Mapped[Decimal | None] = mapped_column(Numeric(28, 8))
    value_text: Mapped[str | None] = mapped_column(String(255))
    unit: Mapped[str | None] = mapped_column(String(16))
    reason_code: Mapped[str | None] = mapped_column(String(32))
    reason_text: Mapped[str | None] = mapped_column(String(255))
    feature_version: Mapped[str] = mapped_column(String(16), nullable=False, default="1.0")
    __table_args__ = (
        UniqueConstraint("run_id", "code", name="uk_run_code"),
        Index("idx_code", "code"),
    )
```

**交付 2：`data/ddl/lab_run.sql`**（参考 DDL，与模型完全一致，含中文注释）

```sql
CREATE TABLE IF NOT EXISTS lab_run (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  run_id VARCHAR(40) NOT NULL COMMENT '内容哈希前12位+时间戳',
  request_hash CHAR(64) NOT NULL COMMENT 'sha256(规范化 profile + 规范化 rows)',
  client_ref VARCHAR(120) NULL COMMENT '业务侧追踪号，如 task-167',
  carrier VARCHAR(20) NULL,
  bank_code VARCHAR(16) NULL,
  row_count INT NOT NULL DEFAULT 0,
  catalog_version VARCHAR(16) NOT NULL DEFAULT '1.0',
  status VARCHAR(16) NOT NULL DEFAULT 'succeeded',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  expires_at DATETIME NOT NULL COMMENT '默认 created_at + 30 天',
  PRIMARY KEY (id),
  UNIQUE KEY uk_run_id (run_id),
  KEY idx_request_hash (request_hash),
  KEY idx_client_ref (client_ref),
  KEY idx_expires_at (expires_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='特征 Lab 一次计算';

CREATE TABLE IF NOT EXISTS lab_run_value (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  run_id VARCHAR(40) NOT NULL,
  code VARCHAR(40) NOT NULL COMMENT '特征代号，如 f_in_total',
  value_decimal DECIMAL(28,8) NULL,
  value_text VARCHAR(255) NULL,
  unit VARCHAR(16) NULL,
  reason_code VARCHAR(32) NULL COMMENT 'missing_column/no_denominator/...',
  reason_text VARCHAR(255) NULL,
  feature_version VARCHAR(16) NOT NULL DEFAULT '1.0',
  PRIMARY KEY (id),
  UNIQUE KEY uk_run_code (run_id, code),
  KEY idx_code (code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='特征 Lab 单项结果';
```

- 验收：库里 `SHOW TABLES` 从 17 张变 19 张；`SHOW CREATE TABLE lab_run` 与参考 DDL 的列名/类型/索引一致（逐个对）

### DA-103 · 口径字典落表（P0，1 天）

目标：46 特征 / 40 指标 / 83 算子可以从表里查，**而不是读 Python**。前端 FE-104、FE-107 都依赖它。

| 表 | 关键列 | 条数 |
| --- | --- | --- |
| `feature_dict` | `code / name / unit / category / expr / description / version / is_builtin` | **46** |
| `metric_dict` | `code / name / unit / group_code / formula / inputs / viz / note / version` | **40** |
| `operator_dict` | `key_ / family / kind / unit / detail / params_json` | **83** |

`data/gen_dict.py` 三条硬要求：

1. **导出而非手抄**：分别从 `rc_platform/capabilities/features/defs.py`（`BUILTIN_FEATURES`，第 130 行起）、
   `rc_platform/capabilities/metrics/mapping.py`（`MetricMapping`）、
   `rc_platform/capabilities/features/library.py`（`operator_catalog()`）读取
2. **幂等**：`INSERT ... ON DUPLICATE KEY UPDATE`，重复跑不报错、不产生重复行
3. **自检**：跑完对比条数，与代码不一致时返回非 0（这是防口径漂移的关键闸门）

```bash
python data/gen_dict.py            # 生成/更新
python data/gen_dict.py --check    # 只校验条数，CI 与验收用
```

- 验收：三张表条数 46 / 40 / 83；`--check` 返回 0；改掉 `defs.py` 里一条特征的名称再跑 `--check` → 必须报错（说明真的在比对）

### DA-105 · 容量估算与清理（P1，0.5 天）

- 估算表：单 run ≈ 46 行 `lab_run_value`；按每日 200 run，30 天 ≈ 6000 run / 27.6 万行 `lab_run_value`，给出 MB 估算（含索引）
- 清理 SQL（**先删子表再删主表**）：

```sql
DELETE v FROM lab_run_value v JOIN lab_run r ON v.run_id = r.run_id WHERE r.expires_at < NOW();
DELETE FROM lab_run WHERE expires_at < NOW();
```

- `docs/Lab容量估算.md` 一页纸：估算过程、`idx_expires_at` 让清理走索引、批量删除建议（每次 5000 行，避免长事务）
- 验收：`EXPLAIN` 清理语句命中 `idx_expires_at`
