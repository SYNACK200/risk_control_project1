## 七、错误码

| code | HTTP | 含义 | 调用方该怎么做 |
| --- | --- | --- | --- |
| `E_AUTH` | 401 | 缺 Key 或 Key 错 | 检查 `LAB_API_KEY` |
| `E_PARAM` | 400 | 参数不合法（codes 超 200、JSON 结构错） | 修请求 |
| `E_NOT_FOUND` | 404 | run 不存在，或 code 未知（会列出未知项） | 先查目录 |
| `E_EXPIRED` | 410 | run 超过 30 天 | 重新提交 |
| `E_LIMIT` | 413 | rows 超 20000 行或 32MB | 分批提交 |
| `E_ENCRYPT` | 400 | PDF 受口令保护（仅 `/v1/runs/file`） | 传 password |
| `E_PARSE` | 422 | 文件解析失败（仅 `/v1/runs/file`） | 改走 rows 入口 |

## 八、rows 里认哪些列

| 列 | 类型 | 例 | 缺了会怎样 |
| --- | --- | --- | --- |
| `txn_date` | `YYYY-MM-DD` | `2021-05-13` | 时间类特征全部不可算（`missing_column`） |
| `trade_time` | `HH:MM:SS` | `10:12:00` | 夜间类 4 个特征不可算 |
| `direction` | `in` / `out` | `out` | 收支类不可算 |
| `amount` | 字符串金额，可带负号 | `"9671.74"` | 绝大多数不可算 |
| `balance` | 字符串金额 | `"9691.67"` | 余额类不可算 |
| `summary` | 字符串 | `"工资"` | 词库类（工资/网贷/博彩）不可算 |
| `counterparty_name` | 字符串 | `"某公司"` | 对手方集中度类不可算 |
| `reference_no` | 字符串 | `"T2021..."` | 少数去重口径受影响 |

## 九、幂等怎么验

```bash
# 同一份请求体连发两次，run_id 必须相同
bash 任务书/00-接口速查.verify.sh   # BE-102 完成后由后端提供该脚本
```

手工验也行：把上面第三节的请求发两次，比较响应里的 `run_id`；然后再把 `rows` 数组顺序倒过来发一次，`run_id` 仍应相同（服务端按内容排序后哈希）。
