## 一、先看清现在乱在哪（实测清单）

| # | 问 | 现状 | 判断 |

## 三、任务卡

### FE-101 · IA 定稿与路由迁移表（P0，0.5 天）
- 产出：`docs/前端信息架构.md`（上面两张表 + 每页职责一句话 + 页面归属图）
- 验收：任何人对「新功能该放哪个菜单」能在表里查到答案
- 注意：**先定稿再动手**，否则搬迁过程会出现两套导航

### FE-102 · 设计令牌与基础组件收口（P0，1 天）
- `web/src/styles/tokens.css`：色板（主色/成功/警示/危险/中性 6 档）、间距（4/8/12/16/24）、圆角、字号、阴影
- `app.css` 只消费 `var(--x)`；`pages/` 下出现裸 `#` 或裸 `px` 边框视为不合格
- `web/src/ui/` 统一 Button / Field / Notice / Table / Tabs / EmptyState（已有 Button/Notice/Field，补齐 Table/Tabs/EmptyState）
- 验收：`grep -rn '#[0-9a-fA-F]\{6\}' web/src/pages | wc -l` 从当前的量降到 < 20，且都是业务语义色（如风险红）

### FE-103 · 导航与布局重构（P0，1 天）
- `BankerApp.tsx`：sider 5 组、当前页高亮、管理员项隐藏逻辑、底部「特征平台：运行中/未连接」状态点
- 页头规范：每页 `h1 + 一句职责说明 + 右侧主操作`（现在 18 个页面各写各的）
- 404 页：列出 5 组入口，不再只写「页面不存在」
- 验收：5 组菜单点击全部到位；旧地址栏粘贴旧 URL 能落到新页面

### FE-104 · 口径中心合并页（P0，1 天）
- 新页 `DefinitionsPage.tsx`：3 个 tab（指标口径 / 核验口径 / 术语），内容直接复用现有三页组件，**不重写表格**
- tab 与 URL 同步（`?tab=`），可直接分享
- 验收：3 个旧入口跳过来后落在正确 tab；三页原有搜索/分页功能不丢

### FE-105 · 任务中心合并（P0，1 天）
- `TaskListPage` 顶部加 tab：列表 / 队列（队列内容 = 现有 QueuePage）
- 队列 tab 保留 5 秒自动刷新，切走即停（现在是一直刷）
- 验收：`/bank/queue` 跳过来落在队列 tab；重试/取消两个动作仍可用

### FE-106 · 报告页视图收敛（P0，1 天）
- 「结论版/明细版」改为 **结论 / 明细** 两个视图；`结论与评分` tab 并入结论视图
- 明细视图 4 个 tab：核验与自检 / 指标 / 证据与定位 / 交易明细
- URL 可分享：`/bank/report/:id?view=detail&tab=metrics`
- 指标点开仍是「计算公式 / 所需输入 / 口径说明 / 关联分布图」（`MetricExplain` 不动）
- 验收：打印/存 PDF 自动回结论视图；`?view=detail&tab=metrics` 直接可打开

### FE-107 · 特征平台入口页（P0，1 天）
- 新页 `FeaturesPage.tsx`：
  - 卡片：Lab 服务状态（`GET /api/v1/lab-bridge/health`，经业务后端代理）、版本、「打开特征平台」按钮（新窗口 `VITE_LAB_PUBLIC_URL`）
  - 目录：调 `/api/v1/features` 的**只读**列表（46 条），按分类分组 + 搜索；每条显示 code/名称/单位/口径说明
  - 明确写一句：「特征计算在独立服务里，这里只做目录与入口」
- 验收：Lab 服务未启动时页面显示「未连接」而不是报错白屏

### FE-108 · 借款侧导航与文案统一（P1，0.5 天）
- 历史页合并进进度页 tab；失败码文案统一走 `api/errors.ts`
- 验收：借款侧 3 个入口 → 2 个；失败码都有中文指引
