## 6. 提交规范

```bash
git checkout -b feat/<板块>-<卡号>        # 例：feat/backend-BE-102
git add -A
git commit -m "feat(lab): BE-102 run 提交与落库"   # <类型>(<范围>): <卡号> <一句话>
git push -u origin feat/<板块>-<卡号>
```

- PR 目标分支：`rebuild/v1`（**不是 dev、不是 main**）
- PR 描述必须带：卡号、改了哪些文件、跑过哪些命令与原始输出、Before/After 截图（涉及界面时）
- 一个 PR 只做一张卡；卡做不完就拆，不要提交半成品

## 8. 常见故障（踩了就查这里）

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| `pytest` 报数据库连不上 | 没带 `MYSQL_PASSWORD` | 命令前加环境变量 |
| 端口占用 `10048` | 旧进程没退 | `netstat -ano | findstr :8010` 后 `taskkill /PID <pid> /F` |
| Windows 编辑文件报 `ReplaceFileW EIO` | Vite/编辑器占着句柄 | 用 Python 脚本写文件，或先停 Vite |
| 前端 PDF 空白、worker 报 `Invalid workerSrc` | `pdf.worker.min.mjs` 没在 `web/public/` | 从 `node_modules/pdfjs-dist/build/` 拷过去 |
| 中文乱码 | 缺 `PYTHONIOENCODING=utf-8` | 加上；PowerShell 另需 `chcp 65001` |
| `web/node_modules` 打不开 | 它是指向 `frontend-admin/node_modules` 的 junction | 不要删；真坏了重建 junction |
| alembic 报 `Migration target rejected` | `data/migrations` 锁定了演示环境（`D:/riskcontroldemo`、3307） | **别用它**；本周建表走 SQLAlchemy 模型（见数据任务书） |
